# GitHub Actions ハンズオン

GitHub Actions を初めて触る人向けのハンズオン用リポジトリです。
このリポジトリを fork して、自分のリポジトリで workflow を動かします。

## 進め方

1. このリポジトリを fork し、Actions を有効化する
2. `.github/workflows/hello-world.yml` を編集して、Actions タブで実行を見る
3. `actions/checkout` を使って、この README.md の中身を出力する
4. リポジトリのルートに `action.yml` を置いて、自分の action を作る

コピー用のコマンドと YAML は [docs/hands-on.md](docs/hands-on.md) にあります。

## このリポジトリの中身

- `.github/workflows/hello-world.yml` — 出発点となる workflow

作業はすべてブラウザ上で完結します。
